一、三个版本怎么选
------------------------------------------------
0. 安装版（setup.exe，推荐给需要开始菜单/桌面快捷方式的用户）
   - 双击 FlangeQueryV2-<版本>-setup.exe，一路下一步即可
   - 默认装到 %LOCALAPPDATA%\Programs\FlangeQuery（当前用户目录，无需管理员权限）
   - 卸载：控制面板「程序和功能」或开始菜单卸载项，不写系统注册表深层
   - 支持自更新：升级时静默运行新版 setup.exe（/VERYSILENT），自动关闭旧进程、覆盖文件并保留快捷方式与卸载项，无需管理员权限

1. 单文件版（文件夹：单文件版）
   - 只有一个 FlangeQueryV2.exe
   - 优点：拷到任何 Win10/Win11 64 位电脑，双击即用，无需安装 Python
   - 缺点：每次启动要把程序解压到系统临时目录（%TEMP%\_MEIxxxx）：
       · 首次运行约 10~25 秒才出窗口（属正常，不是卡死）
       · 再次运行约 3~6 秒（系统缓存生效后）
       · 要求 C 盘剩余空间 ≥ 150 MB
       · 若程序被强制结束，临时目录可能残留，可定期清理 %TEMP% 下 _MEI 开头文件夹

2. 文件夹版（文件夹：文件夹版）
   - 整个 FlangeQueryV2 文件夹，双击里面的 FlangeQueryV2.exe
   - 优点：秒开，无解压等待，不占 C 盘临时空间
   - 缺点：拷贝 / 发人时必须带整个文件夹（不能只拷 exe）
   - 日常放自己电脑上用，推荐这个


二、运行环境
------------------------------------------------
- Windows 10 / 11，64 位
- 无需安装 Python、无需安装 PyQt5，全部已打包
- 数据文件已内置，不依赖外部路径，从任何目录启动都可以


三、功能速览
------------------------------------------------
顶部工具条共 6 个分类页签：法兰 / 密封件 / 管件 / 钢管 / 波纹管 / 容器法兰

【密封件】（本次新增，原"密封面"页签改名并完整开发）
   内置 8 个化工行业法兰用垫片标准数据：
   - PN 系列：HG/T 20606 非金属平垫、20607 PTFE 包覆垫、20609 金属包覆垫、
             20610 缠绕式垫片、20611 齿形组合垫、20612 金属环垫
   - Class 系列：HG/T 20627 非金属平垫、20631 缠绕式垫片
   另含「密封面型式参考」：突面 RF / 凹凸面 MFM / 榫槽面 TG / 环连接面 RJ（复用示意模板）
   支持按 压力等级(PN/Class) / 公称尺寸 DN / 垫片型式 筛选；
   右侧图形卡显示垫片断面示意图 + 关键尺寸（内径 D1、外径 D2、厚度 T、节圆 P 等）叠加标注。

【法兰】GB/T 9124 法兰、HG/T 20592/20615 化工法兰、HG/T 20623 大直径、
       NB/T 47023 容器法兰 等
【管件】GB/T 12459 / GB/T 13401 钢制对焊管件（弯头 / 三通 / 异径管 / 管帽）
【波纹管】（本次新增，与法兰/管件并列的独立模块）
   U形波纹管膨胀节几何参数表（70B125-2002 附录A 表A.1）：
   - 覆盖 DN50 ~ DN2800 共 44 个规格（含 100a/150a/350a/400a 等 a 型变型）
   - 查询条件 = 公称直径(DN) / 接管规格
   - 字段：接管规格 dᵢ×S、波谷外径 Do、波高 h、波距 q、波谷半径 r、
           直段长度 Lt、一次成型最多波数 N、一个波展开长度 a
   - 右侧图形卡显示 U 形波纹管剖面示意 + DN/Do/接管/h/q/r/Lt 叠加标注
【钢管】GB/T 17395-2024（普通/精密/不锈钢 三表，按标准 PDF 全文录入）：
      查询条件 = 公称直径(DN) / 外径(D_o) / 壁厚(S)，结果直接显示每米重量(kg/m)；
      ANSI B36.10/36.19、HGJ514/528、HG/T 20553 等壁厚系列

通用功能：左树检索 → 中表筛选 → 点行看图形与详情；顶栏支持导出 CSV / 打印。
导出会保留当前页面的完整列结构（含钢管 Sch、垫片 PN/Class、波纹管几何参数等
页面特有字段）；打印使用可缩放的打印预览，不再直接跳过预览。


三-补、钢管（GB/T 17395-2024）数据按标准 PDF 全文录入说明（2026-10-20 更新）
------------------------------------------------
【钢管】页签下原「GB/T 17395 钢管尺寸系列」（ASME Schedule 壁厚体系）已
整体替换为**严格按 GB/T 17395-2024 正式 PDF 四张表全文录入**的三张表，
旧 Schedule 体系不再作为主数据（避免"数据不全"问题）。三表均采用**长表（tidy）
格式**：每个 (外径 × 壁厚) 组合一行，便于按三维条件检索并直接给出每米重量：
- 普通钢管（表1 普通钢管 S≤65 + 表2 普通钢管 S>65 合并）：
  4925 行；列 = DN, DN2(NPS), D_o, 系列, 壁厚S(mm), 每米重量(kg/m)；
  含系列1/系列2/系列3（按表1 网格检测，跨页一致、符合 ISO 4200）。
- 精密钢管（表3）：1014 行；列 = DN, DN2(NPS), D_o, 壁厚S(mm), 每米重量(kg/m)；
  定径管不标 系列（标准原文无此列）。
- 不锈钢管（表4）：2608 行；列 = DN, DN2(NPS), D_o, 系列, 壁厚S(mm),
  每米重量(kg/m), 标准尺寸(●)；标准表4 仅给出 ● 尺寸可用性、不列重量，
  此处按同一几何公式补算理论重量，并以「标准尺寸」列保留原 ● 标记。
查询条件（gbt_pipe 视图）= 公称直径(DN) / 外径(D_o) / 壁厚(S)；
结果表与详情面板均显示「每米重量(kg/m)」。
数据来源：GB/T 17395-2024 PDF 网格墨迹提取（gbt_2024.json，309 个外径行，
系列归属跨页零警告、连续性校验零警告）。
理论重量按标准式(1)：W = 0.0246615 × (D − S) × S（ρ=7.85），
小数位与修约按 GB/T 8170（四舍六入五留双），全量公式核对零偏差。
D/S 均取括号外数值（标准表注：重量按括号外公称外径与公称壁厚计算）。
DN / NPS 为辅助检索列（按 GB/T 1047 / HG/T 20553 惯例映射，标准原文无此两列）。
数据重建脚本：gen_gb17395_2024.py（消费 gbt_2024.json 生成长表 CSV）；
旧脚本 gen_gb17395.py / gen_gb_data.py 为 Schedule 体系遗留，已停用。


四、数据来源与精度提示（重要）
------------------------------------------------
垫片尺寸表来源分两类，使用前请知悉：
1. 干净 OCR 转写（可信度高）：HG/T 20606（FF/RF/MFM/TG）、HG/T 20609
2. 公开标准表补全（建议核对正式 PDF 后再用于正式出图）：
   HG/T 20607、20610、20611、20612、20627、20631
   上述 6 项因本地 PDF 文本层无可读数字，数值由公开标准数据转写，并已在
   gen_gasket_data.py 顶部 `# 缺口/疑问` 明确标注；厚度 T、包边宽 b 及高压力等级
   大口径尺寸可能需复核。涉及工程出图，请用正式标准 PDF 校验后再用。


五、已知说明（非故障）
------------------------------------------------
1. 单文件版首次启动慢（解压所致），后续启动会快
2. 单文件版运行时任务管理器可能出现两个同名进程（引导程序 + 主程序），属正常机制
3. 杀毒软件可能对首次运行的新 exe 扫描几秒，如弹窗选"允许"即可
4. 业务数据全部本地运行；仅启动时（约 4 秒后）静默访问公开 GitHub Releases 检查
   更新，不收集任何用户数据；窗口位置和上次页签会写入当前用户配置
   （HKCU\Software\FlangeQuery\FlangeQueryV3），日志写入
   %LOCALAPPDATA%\FlangeQuery\logs\FlangeQuery.log（1 MB × 3 份轮转）
5. exe 当前未做代码签名，Windows SmartScreen 可能提示未知发布者


六、半自动更新（V3.78.2 起）
------------------------------------------------
- 默认更新源：GitHub Releases（公开仓库 wodeya163/FlangeGetData，免鉴权）。
  启动约 4 秒后静默检查一次；「关于」对话框内可手动点「检查更新」。
- 发现新版：弹窗确认 → 后台下载 → SHA256 校验 → 写更新脚本 → 程序退出并由脚本
  完成升级后自动重启。安装版静默运行 setup.exe，文件夹版覆盖整包，
  单文件版替换 *-onefile.exe，三种版本均支持自更新。
- 关闭检查：设置环境变量 FLANGE_NO_UPDATE=1（内网/调试环境）。
- 切换更新源（改 updater.py 顶部常量或设同名环境变量）：
  A) GitHub（默认）：FLANGE_GITHUB_REPO=owner/repo
  B) Gitee（备用）：FLANGE_GITEE_REPO=owner/repo，需在 Gitee Release 上传
     version.json + *-folder.zip（单文件版另需 *-onefile.exe）
  C) 通用 http(s)：两者留空，把 updater.UPDATE_BASE_URL 指向你的 http(s) 目录，
     在该目录放 version.json + folder zip
  ※ WorkBuddy 云存储与消费级网盘均无稳定免鉴权直链，不适合作为更新源。
- 发布新版：改 version.py 的 APP_VERSION 并推送到 main，GitHub Actions 会自动
  构建并发布 version.json + *-folder.zip + *-onefile.exe；也可本地手动运行
  python tools\_publish_update.py --build --github wodeya163/FlangeGetData --notes "更新说明"
- 网络抖动（WinError 10054/10060）会自动重试 3 次；若 github.com 下载域名被重置，会自动改走 GitHub API 资产通道（release-assets.githubusercontent.com）。
