## 二、复核结果

- **8 类共 1143 行，(PN,DN) 键与 PDF 完全对应，无缺失、无多余，公共尺寸逐项零差异。**
- 原程序这 8 个页签复用 `HGT20592_*.csv`，而 HG/T 20592 与 GB/T 9124.1 属不同标准体系，存在 596 处固有差异
  （典型：PN10 DN50 C 值 19→20、PN16 DN600 C 值 52→55、法兰盖大口径 C 值与 Th 螺纹标记差异等）。
  这不是导入错误，而是**数据源用错标准**——本次已为 GB 页签建立独立真值表，HG/T 页签数据保持不变。
- 部分差异曾误判为提取错位（如 PJSE 表58 的 B 列、法兰盖 C 列括号内角标），经 PDF 页面高分辨率渲染目视核验后确认解析器处理正确。
