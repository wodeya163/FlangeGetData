# 键联接选型工具对齐清单

对齐目标：保留 FlangeQueryV2 的浅色主题，功能与交互逐步靠拢原版。  
当前版本：V3.56.0（本清单随 3.57.0 交付）

## 二、交互与结果

- 智能选型结果可“转到校核页”，按页签名称定位；
- 智能选型结果可“保存到库”；
- 选型库支持双击或“载入选中”恢复参数；
- 首页历史支持双击恢复、删除、清空；
- 参数通过 QSettings 持久化；
- 结果支持复制、TXT、结构化 CSV、PDF；
- PDF 支持 A4/A3、纵向/横向；
- 支持打印预览；
- 提供键联接帮助和公式说明；
- 平键、半圆键、楔键显示公差与配合；
- 键材料 45 钢/40Cr/不锈钢对应不同剪切许用应力。

## 三、标准与公式

- 普通平键：GB/T 1096-2003，键宽 h8、键高 h11、键长 h14；
- 半圆键：GB/T 1099.1-2003，键宽 h9、键高 h11、键径 h12；
- 楔键：GB/T 1564/1565-2003，键宽 h9、键高 h11、键长 h14；
- 矩形花键：GB/T 1144-2001，齿侧 H7/f7、外径 H7/h6、内径 H7/g6；
- 平键挤压：`σp = 2T/[d(h/2)(L-b)]`；
- 平键剪切：`τ = 2T/[d b (L-b)]`；
- 楔键：`σp = 12T/[b l (6μd+b)]`；
- 花键：`p = 2T/(0.75 N h l dm)`。

## 五、有意保留的差异

1. **主题**：按要求只保留浅色主题，不实现原版深色/换肤；
2. **欢迎与锁定对话框**：原版含 WelcomeDialog/LockDialog，属首次运行/授权交互，集成版不复制；
3. **选型库存储**：使用 QSettings JSON，原版使用 SQLite 规格库；功能等价，未复用原库表结构；
4. **新增能力**：PDF、打印预览、页面设置、结构化 CSV、帮助文档，为集成版增强，不属于原版。

## 六、已知边界

- 键规格表覆盖常用轴径范围，超出范围会给出无匹配提示；
- 半圆键/花键为常用规格子集，不等于完整标准手册；
- 结果为工程参考，最终设计需由专业人员结合工况与现行标准确认。
