## 一、行级复核状态

加载数据时，`core.review.annotate_rows()` 为每一行附加：

| 字段 | 含义 |
|---|---|
| `review_status` | `verified` / `partial` / `inferred` / `alias` / `descriptive` |
| `review_label` | 中文标签 |
| `复核状态` | 表头/导出使用的列 |
| `review_source` / `数据来源` | 行级来源 |
| `face_status` | `complete` / `missing` |

规则：

- 行内已有 `review_status` / `review_source` 时优先使用行值；
- 否则继承文件级 `review_for(csvf, std)`；
- 返回值是新行对象，不修改原始数据。

界面：

- 表格**第一列**显示“复核状态”；
- `已核对` 绿色、`部分核对` 灰色、`推断/补全` 黄色、`alias` 橙色；
- 悬停显示数据来源；
- 选中行标题追加“本行复核：…”；
- 面型尺寸缺失时提示“面型尺寸缺失，图形为近似”。

导出：

- CSV/XLSX 保留每行 `复核状态`、`数据来源`；
- 行级值不会被文件级默认值覆盖。

## 三、面型缺失策略

- `RF_d` 或 `RF_f1` 为空：`face_status=missing`；
- 绘图继续画轮廓，但标签标“近似”；
- 选中行提示面型尺寸缺失；
- 不把推断值伪装成标准值；
- 不会因为缺面型尺寸而隐藏整行。

后续需要补真实面型表后，`face_status` 自动变为 `complete`。
